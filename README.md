# OpenWork

**Build together. Learn together. Create opportunities to contribute.**

OpenWork is a **free, open-source, community-driven platform in development** where people will be able to propose useful software projects, find collaborators, form teams, and launch real products together.

Our first project is building **OpenWork itself**. Once it is launched, people will be able to start and contribute to many other open-source projects through the platform.

> **Status: Planning - founding contributors welcome.** There is no deployed OpenWork application yet. The functionality described below is our vision, not a claim about working features.

## Why OpenWork?

Students, recent graduates, career changers, and unemployed professionals often find it difficult to get their first opportunity to work with a real team. Personal projects and tutorials help, but don't always provide the experience of collaborating, reviewing code, testing, maintaining, and delivering something that people actually use.

OpenWork aims to make meaningful collaboration easier to find. It should also help non-developers bring real problems to people who can help solve them.

**OpenWork is not an employer, internship program, placement agency, or job guarantee.** Contributors can accurately showcase the real work they complete, without implying employment or credentials they haven't earned.

## What will the platform do?

1. **Propose projects.** Anyone, including non-developers, can describe a real problem worth solving.
2. **Discover projects.** Find community projects by topic, required skills, and development stage.
3. **Form teams.** Project maintainers identify roles and welcome developers, testers, designers, writers, and mentors.
4. **Collaborate in the open.** Work through issues, code reviews, testing, documentation, and releases using established open-source tools.
5. **Ship and maintain.** Publish useful software for real users and keep improving it.
6. **Show real contributions.** Link to genuine pull requests, features, tests, designs, and released work.

The **first release** will focus on project proposals, discovery, contributor interest, basic moderation, and repository links. We will determine the implementation together.

## Who can join?

Everyone willing to collaborate respectfully is welcome:

- Software engineers and developers (frontend, backend, full-stack, mobile, data, and other fields)
- QA engineers, testers, and accessibility specialists
- UI/UX and product designers
- Technical writers and documentation contributors
- Students, recent graduates, self-taught developers, and career changers
- Experienced engineers who can review or mentor
- Non-developers with meaningful problems, ideas, or product feedback

You do **not** need previous professional experience to participate.

## Guiding principles

- **Open source:** The OpenWork platform is developed publicly under [Apache License 2.0](LICENSE).
- **Free to use:** No paywalls, subscriptions, or paid contributor privileges.
- **Self-hostable:** A reproducible, independently deployable version is a requirement for the platform—not a feature that exists yet.
- **No mandatory paid dependencies:** Core functionality should not require commercial APIs or subscriptions. Running a server may still have infrastructure costs.
- **Community-driven:** Open proposals, transparent decisions, and a documented path to shared maintenance.
- **Privacy-first:** Public code and plans; protected credentials, personal information, and sensitive reports.
- **Honest experience:** Real, attributable contributions—not invented employment, internships, or certifications.
